# Sample Gem Designs

This folder contains sample .asc files for testing and development.

## Files

### simple-test.asc
- **Symmetry:** 4-fold with mirror (8 positions)
- **Index Gear:** 96
- **Facets:** 5 (table, crown, girdle, pavilion, culet)
- **Purpose:** Basic parser validation and testing

### standard-round-brilliant.asc
- **Symmetry:** 8-fold with mirror (16 positions)
- **Index Gear:** 96
- **Facets:** 57 facets total (classic brilliant cut)
- **Material:** Quartz (RI 1.54)
- **Purpose:** Traditional brilliant cut reference

### portuguese.asc
- **Symmetry:** 4-fold with mirror (8 positions)
- **Index Gear:** 96
- **Facets:** Multiple tiers with intricate faceting
- **Material:** Sapphire (RI 1.76)
- **Purpose:** Complex design with multiple break facets

## External Resources

For more designs, visit:
- [facetdiagrams.org](http://facetdiagrams.org/) - Large database of community designs
- Filter for "Open designs" to find freely available patterns

## File Format

All .asc files follow the GemCad ASCII format:
- Human-readable text format
- Line-based commands (g, y, I, H, a, F)
- See `project-resources/gem-forge-project-spec.md` for format details
